١. الحماية تبدأ قبل كتابة السجل

كل خدمة في مسار العرض تكتب حقولاً محددة تحتاجها لمراقبة الطلب. Laravel يبني سطر JSON بقائمة سماح، والمستودع يكتب اسم RPC وحالته ومعرّف التتبع، والبوابة ترسل الحالة والمدة وعنوان النسخة. يصبح مرور بيانات الاعتماد عبر HTTP مستقلاً عن الحقول التي تختارها هذه السجلات.

الملفما الذي أضفناه أو عدّلناه؟
SafeJsonFormatter.php · logging.phpمنسّق جديد وقناة مضافة في الإعداد الموجود. يختاران الحدث والسياق المسموحين قبل كتابة JSON.
TraceRequest.php · docker-compose.req6.yml · router.phpملفات جديدة تقيّد الترويسة بصيغة UUID، وتفعّل القناة، وتضبط خادم PHP لبيئة العرض.
nginx-format.conf · nginx-access.conf · nginx.confملفا قياس جديدان يحددان حقول سجل البوابة، وملف Nginx الموجود عُدّل لتحميلهما في بيئة المتطلب السادس.
handlers.ts · server.ts · seed.tsتعديلات على سجل المستودع. يبقى الخطأ الداخلي رسالة عامة، وتُكتب بيانات العملية المسموحة في موضع موحّد.
OrderService.php · RetryInventoryCompensations.phpتنظيف سجلات فشل الطلب وتعويض حجز المخزون من نصوص الاستثناء الخام.
ObservabilityTest.php · verify.pyاختبار مستقل للمنسّق والترويسة، واختبار عبر البوابة وخدمات التطبيق الفعلية.

افتح backend/my-project/app/Logging/SafeJsonFormatter.php · الأسطر 1–57

<?php

namespace App\Logging;

use Illuminate\Support\Str;
use Monolog\Formatter\JsonFormatter;
use Monolog\LogRecord;
use Throwable;

class SafeJsonFormatter extends JsonFormatter
{
    // Exception messages, SQL bindings, mail bodies and arbitrary library messages may contain credentials.
    private const EVENTS = [
        'HTTP request started', 'HTTP request finished', 'Outbox publication confirmed',
        'Outbox publication deferred', 'Outbox publisher recovering', 'Order email processing',
        'Order email processed', 'Order email deferred', 'Order email worker recovering',
        'Order confirmation accepted by delivery transport',
        'MOCK DELIVERY: order confirmation processed without an external email',
        'Could not determine whether an order reservation was persisted',
        'Could not verify order persistence before compensation',
        'Order creation failed, attempting stock release', 'Stock compensation recorded for retry',
        'Inventory compensation retry failed', 'Order dashboard cache invalidation failed',
        'Order broadcast enqueue failed after commit', 'Order notification failed after commit',
    ];

    public function formatBatch(array $records): string
    {
        return implode('', array_map($this->format(...), $records));
    }

    public function format(LogRecord $record): string
    {
        $row = ['time' => $record->datetime->format('Y-m-d\TH:i:s.uP'), 'level' => $record->level->getName(),
            'message' => in_array($record->message, self::EVENTS, true) ? $record->message : 'Application diagnostic'];
        foreach (['event_id', 'correlation_id'] as $key) {
            $value = $record->context[$key] ?? null;
            if (is_string($value) && Str::isUuid($value)) {
                $row[$key] = $value;
            }
        }
        foreach (['order_id', 'attempt', 'status', 'operation_id', 'compensation_id'] as $key) {
            if (isset($record->context[$key]) && is_int($record->context[$key])) {
                $row[$key] = $record->context[$key];
            }
        }
        foreach (['delivery_mode' => ['external', 'mock'], 'destination' => ['retry', 'dead_letter']] as $key => $values) {
            if (in_array($record->context[$key] ?? null, $values, true)) {
                $row[$key] = $record->context[$key];
            }
        }
        if (($record->context['exception'] ?? null) instanceof Throwable) {
            $row['exception_type'] = $record->context['exception']::class;
        }

        return json_encode($row, JSON_THROW_ON_ERROR)."\n";
    }
}
الأسطر ١٣–٢٤
EVENTS قائمة ثابتة من رسائل البرنامج المعروفة. يمنع ذلك نشر نص رسالة ديناميكية إذا اشتمل على بيانات مستخدم أو استثناء. يستخدم الحدث العام Application diagnostic إذا لم يجد نصاً مطابقاً.
الأسطر ٢٦–٣٤
تعيد formatBatch استعمال دالة السطر الواحد، لذلك تغطي السياسة الوضع المفرد والدفعي. يبني $row من الوقت ومستوى السجل والاسم المسموح.
الأسطر ٣٥–٥٠
يُقبل event_id وcorrelation_id إذا كانا UUID صالحين، وتُقبل حقول الطلب والمحاولة والحالة كأعداد صحيحة فقط. الحقول النصية مثل delivery_mode محدودة بقيم معروفة. لا يضيف الكود password ولا Authorization ولا رؤوس الطلب ولا extra.
الأسطر ٥١–٥٥
إذا كان السياق يحمل استثناء من نوع Throwable يكتب اسم الـclass فقط. قد تضم رسالة استثناء قاعدة البيانات نص SQL وبياناته، لذلك يختار الكود ::class ولا ينسخ تفاصيل الاستثناء. يكوّن json_encode السطر النهائي من الحقول التي نجحت في الشروط.

    public function handle(Request $request, Closure $next): Response
    {
        $incoming = $request->header('X-Correlation-ID');
        $id = is_string($incoming) && Str::isUuid($incoming) ? strtolower($incoming) : (string) Str::uuid();
        $request->attributes->set('correlation_id', $id);
        $observed = config('logging.default') === 'observability';
        if ($observed) {
            Log::info('HTTP request started', ['correlation_id' => $id]);
        }
        $response = $next($request);
        $response->headers->set('X-Correlation-ID', $id);
        if ($observed) {
            Log::info('HTTP request finished', ['correlation_id' => $id, 'status' => $response->getStatusCode()]);
        }

        return $response;
    }

٥. الأوامر التي تعرضها للأستاذ

من PowerShell نفّذ wsl -d Ubuntu واترك نافذة Ubuntu مفتوحة طوال العرض. في Ubuntu على جهاز ملاد المجهّز:

cd /mnt/e/Projects/internet-applications
bash ops/req6/compose.sh --local-sources up -d --no-build --pull never --wait

  1. cd ينتقل إلى جذر المشروع على قرص E.
  2. يجمع compose.sh ملفات البنية وإعداد المقابلة والمراقبة ضمن مشروع ecommerce-req6. يفعّل --local-sources ربط الكود الحالي على صور العرض الجاهزة. يشغّل up -d الخدمات في الخلفية، ويطلب --no-build --pull never استخدام الصور المحلية، وينتظر --wait جاهزية الحاويات.
  3. يتأكد --monitoring-only من ظهور لوحة Grafana ذات الرسوم الستة، ووصول Prometheus إلى مصدرَي HTTP وRabbitMQ، ووجود قاعدتي التنبيه. بعدها تستطيع بدء الاختبار الفعلي.
