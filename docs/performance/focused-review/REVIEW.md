## Reproduce

Use the existing isolated test container with explicit SQLite settings for the default suite and phpunit.mysql.xml for guarded MySQL tests. Copy perf/verify-compression.php into the backend container and run it with --expect-gzip. The paired k6 script is perf/k6/compression.js; use the same dataset, VUs and duration and separate output directories. Saved image IDs identify both measured runtimes. Earlier pre-index/cache evidence remains under docs/performance/baseline and results; do not reset the current 300,004-order dataset to replay it.

The HTML is generated by node perf/build-performance-guide.cjs and validated by node perf/verify-performance-guide.cjs. Source snippets are embedded from current files and checked byte-for-byte after normalizing line endings. The guide is standalone and needs no external assets.
